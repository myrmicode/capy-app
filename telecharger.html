Installer Capy

Pour les parents. Aucune publicité, aucun traceur.

Sur la tablette : l’application

La version complète, avec l’appareil photo pour la fiche de l’école et la voix de Capy.

Télécharger Capy (APK)

  1. Touchez le bouton ci-dessus depuis la tablette, dans Chrome.
  2. Ouvrez le fichier téléchargé. Android demande d’autoriser l’installation depuis Chrome : acceptez.
  3. Touchez « Installer ».

Pour une nouvelle version, refaites la même chose : elle remplace l’ancienne, les profils et les progrès sont gardés.

Ou bien : le site installable

Plus léger, toujours à jour, sur tablette comme sur ordinateur.

Ouvrir Capy

  1. Ouvrez Capy dans Chrome.
  2. Menu ⋮, puis « Ajouter à l’écran d’accueil » (ou « Installer l’application »).

Les profils restent dans le navigateur de l’appareil : ils ne passent pas d’une version à l’autre.
